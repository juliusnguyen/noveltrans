# 038 — Punctuation-only lines become silence — PLAN

## Design decisions

| Decision | Rationale |
| --- | --- |
| **Fix it in `clean_for_tts`**, not in the chunker. | It is a text-cleaning concern, and it is the one place both consumers already go through — the render (`base.py:129`) and the Audio tab's preview (`tab_audio.py:442`). Fixing it in the chunker would leave the preview showing text that isn't what gets spoken, which is the sort of divergence that costs an hour to diagnose later. |
| **"Speakable" = contains a letter or a digit.** | Anything else on a line is punctuation, and punctuation alone has no pronunciation — that is the entire bug. Digits count, so a chapter-number line `1` still gets read. Letters are already Latin-only by the time this runs, so the check needs no script logic of its own. |
| **Drop the line's content and let the existing blank-run collapse make the pause.** | `_BLANK_RUN_RE` already caps runs at one blank line, so `A\n\n“…”\n\nB` becomes `A\n\nB` — a normal paragraph break, which `synthesize_chapter` already renders as `paragraph_gap_seconds` of real silence. The beat the author wrote survives *as silence*, which is what they meant. No new gap machinery, no new setting. |
| **Only whole lines, never mid-sentence punctuation.** | `Anh ta ngập ngừng… rồi im lặng.` must keep its ellipsis: that is prosody, and breaking it would be a worse regression than the bug. Operating line-by-line makes this structural rather than a matter of careful regex. |
| **Runs after `extra_remove`, before the whitespace tidy.** | `extra_remove` can itself empty a line (a user stripping `()` turns a `(…)` line into punctuation-only), so the check has to see the final characters. Running before the tidy means the existing collapse rules clean up after it, instead of needing their own pass. |
| **No new setting.** | "Say the ellipsis out loud" is not a preference anyone holds. Adding a toggle would mean designing, labelling and testing a switch whose off position is the bug. |

## Implementation

### `src/noveltrans/tts/clean.py`

```python
_SPEAKABLE_RE = re.compile(r"[^\W\d_]|\d", re.UNICODE)   # any letter or digit


def _has_speech(line: str) -> bool:
    """True if a line has anything an engine could pronounce.

    A line of pure punctuation — `“…”`, `……`, `“?”`, `- - -` — is a *beat*, and Vietnamese
    web novels use it constantly for a silent reply in dialogue. Handed to the engine it
    comes out as a noise instead: `split_sentences` gives it its own chunk, feature 028's
    `merge_short_chunks` glues that 3-character chunk onto the neighbouring sentence, and
    the voice tries to pronounce it.
    """
```

In `clean_for_tts`, after `extra_remove` and before `_MULTISPACE_RE`:

```python
# Drop lines with nothing to say, keeping the newlines so the blank-run collapse below
# turns the hole into a paragraph break — i.e. into real silence, which is what the
# author wrote. Ellipses INSIDE a sentence are untouched; those are prosody.
cleaned = "\n".join(line if _has_speech(line) else "" for line in cleaned.split("\n"))
```

## Test plan

`tests/test_tts_clean.py`:

- `test_an_ellipsis_only_line_becomes_a_paragraph_break` — the reported case, using the
  user's exact three-paragraph excerpt.
- `test_an_ellipsis_inside_a_sentence_is_untouched` — **the anti-regression**; this must
  never become silence.
- Parametrised over the shapes these novels actually use: `“…”`, `……`, `"..."`, `“?”`,
  `“!”`, `- - -`, `***`.
- `test_a_digit_only_line_survives` — `1` is speakable.
- `test_a_line_emptied_by_extra_remove_is_also_dropped` — ordering matters.
- `test_an_all_punctuation_chapter_cleans_to_empty` — feeds the existing
  "Chương không có nội dung để đọc." error rather than a crash.

`tests/test_tts.py` — end to end through `split_sentences`: the reported excerpt yields
two chunks (not three, and not one with the ellipsis glued on), proving the fix survives
`merge_short_chunks`.

## Risks

1. A punctuation-only line *between* two lines of one paragraph (single newlines) becomes
   a paragraph break rather than vanishing silently. Rare in practice, and the outcome —
   a slightly longer pause — is benign.
2. A line of pure emphasis punctuation the author meant as sound (`“!!!”` as a shout) is
   now silence. It was previously an engine noise, so this is still an improvement, and
   there is no way to distinguish the two from text alone.
