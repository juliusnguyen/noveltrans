# 048 — Manual chapter authoring (own novel, no scraping)

Support novels I write myself, instead of scraping from a website.

Flow:

1. **Tải truyện** — I can create a chapter by name (no source URL / no scraping).
2. **Dịch** — I can paste my own text into `Bản gốc` for that chapter.
3. **Nghe audio** — I can generate the audio from that chapter.

So the pipeline should work end-to-end for manually authored chapters, the same
way it does for scraped ones.
