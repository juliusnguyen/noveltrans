# 036 — Flush-left / flush-right alignment for the thumbnail title

## The ask

> support the flush right and flush left

## Settled scope

- **The novel title only.** It is the one text that wraps onto several lines, so it is
  the only one where alignment is visible. `PHẦN N` and the tagline keep centring on
  their own anchor point, unchanged.
- **Two values, left and right.** No centre option — exactly the toggle asked for.

## What exists today

`compose_thumbnail` draws the title as a left-aligned block:

```python
title_x = round(W * title_pos[0])
max_text_w = max(round(W * 0.2), min(round(W * 0.62), W - title_x - margin))
lines = _wrap_title(vn_title, title_font, max_text_w)
for line in lines:
    _draw_glow_line(bg, (title_x, y), line, ...)   # every line starts at the same x
```

`title_pos` anchors the block's **top-left**, and every wrapped line is drawn at that same
`title_x`. The wrap budget is measured rightwards from the anchor.

Feature 035 added `title_scale`, so the title's pixel size is already variable — which
matters here, because line widths (and therefore right edges) move with it.

## Open questions for `/plan`

- What `title_pos[0]` means when the title is flush right: still the block's left edge
  (so the ragged edge lands wherever the longest line ends), or the **right** edge the
  lines are pushed against. The second is what "flush right" normally means and what
  makes the control useful, but it reinterprets a saved setting.
- How the wrap budget is computed in right mode — measuring rightwards from the anchor
  is wrong once the anchor is a right edge.
- Whether existing projects must render identically when the setting is left (they
  must — 034's "Cập nhật ảnh bìa" pushes covers to already-published videos, so any
  silent shift reaches a live channel).
- Where the control lives: the cover editor beside the position/size sliders, and how it
  interacts with dragging the title block on the preview.

## Out of scope

- Alignment for `PHẦN N` / the tagline.
- A centre option.
- Vertical alignment or justification.
