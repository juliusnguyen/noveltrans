# 107 THUMBNAIL-ALL-CRASH

Bấm nút tạo lại toàn bộ ảnh bìa (phần tạo toàn bộ thumbnail) làm app crash.

## Báo cáo (macOS 27.3, python3.12, PySide6 6.11 / Qt 6.11)

- Exception: `EXC_BREAKPOINT (SIGTRAP)`, trong `CoreGraphics CGImageCreate` → `verify_image_parameters` → `valid_image_colorspace`.
- Đường gọi (trên main thread): `QImage::toCGImage()` ← `libqcocoa` (đặt con trỏ) ← `QGuiApplication::setOverrideCursor(QCursor)` ← `Sbk_QGuiApplicationFunc_setOverrideCursor` ← code Python trong slot của `QPushButton`, lúc đang chạy trong `QDialog.exec()` (modal).
- Code liên quan: `src/noveltrans/gui/tab_video.py:2533` trong `_regen_all_thumbnails`: `QApplication.setOverrideCursor(Qt.CursorShape.WaitCursor)`. Chỗ tương tự: `src/noveltrans/gui/tab_translate.py:1004`.

## Ghi chú ban đầu

- Crash nằm trong Qt khi chuyển con trỏ WaitCursor thành ảnh trên macOS này, không phải lỗi logic của việc tạo ảnh bìa. `try/except` trong vòng lặp không bắt được SIGTRAP.
- Cần xác định: có tái hiện được ngoài dialog modal không, và có crash ở `tab_translate.py` không.
