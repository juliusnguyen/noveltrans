### Judgement calls made here rather than deferred

- **Reversing the order is a deliberate reversal, not a tidy-up.** `bilingual_title`'s
  docstring justified original-first ("the Chinese is how the user recognises the novel on
  the source site"). The counter-argument, now recorded in `novel_label`: a tab column shows
  roughly 20 characters, and the old order spent all of them on text the user does not think
  in. The original is still present one field along, serving exactly the recognition the old
  order was for.
- **Replaced `bilingual_title` outright** rather than keeping both. Two helpers differing
  only in field order is precisely how the four call sites would drift.
- **`display_title` wins the first slot.** It is the user's own name for the novel
  (feature 025's override, which exists to drop tags like "[ĐM/EDIT] "), so it should beat
  the raw machine translation wherever the novel is named.
- **Separator `  —  ` → ` — `.** Three parts at the old double-spaced width read as three
  separate columns. The picker's single-spaced form was already the narrower of the two
  conventions in the codebase.
- **The scrape header drops the source** (`with_source=False`): it sits directly under the
  URL box the novel was scraped from, so the domain is already on screen.

### Three Qt behaviours that would each have shipped a visible bug

All three were measured by the plan agent in offscreen Qt, not inferred:

1. **`initStyleOption` pre-elides the label** against the *vertical* text rect (~20px), so
   the option arrives as a bare `"…"`. A naive custom `paintEvent` renders a column of
   ellipses. The bar reinstates `tabText(i)` and re-elides against the row.
2. **Qt places the close button from the transposed frame** — measured at (86, 0) in a
   190×32 row, i.e. top-centre. Re-asking the style with a North-shaped option gives
   (171, 8). Done from `paintEvent`, not just `tabLayoutChange`, because scrolling re-runs
   Qt's own `layoutWidgets` without a layout-change callback.
3. **Corner widgets get zero geometry on a West/East bar** — `QRect(0,0,0,0)` while
   `isVisible()` stays `True`. The ⚙ and ＋ buttons would simply have vanished on the new
   default. Hence `tab_toolbar`.

`QProxyStyle` (the obvious fix for #2) **segfaults** in PySide6 under an app-wide
stylesheet — the proxy takes ownership of the app's `QStyleSheetStyle`. Not used.

### A test-hygiene finding, pre-existing

`tests/test_main_window.py`'s `main` fixture isolates `AppState` but **not**
`config.library_dir`, which falls back to the real `~/NovelTrans`. A fresh workspace's
picker auto-selects the first project it finds there, so a test window is never actually
blank — it silently loads whichever novel sorts first on the developer's machine. Two new
tests tripped over this. They build their own window against an empty tmp library rather
than papering over it; the shared fixture is left alone (changing it could shift other
tests' behaviour, and that is its own change).
