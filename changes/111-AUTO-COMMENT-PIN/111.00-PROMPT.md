# 111 AUTO-COMMENT-PIN

## Request

After publishing a video, automatically post a comment on that video with the command text, then pin the comment to the video.

## Notes

- Runs as part of the publish flow in `src/noveltrans/youtube_upload.py`, after `_finish` confirms the publish.
- Needs a source for the command text. The request says "the command" but doesn't say which text or where it comes from. To be confirmed in `/plan`.
- Pinning and commenting are both Studio/YouTube actions. Plan must check whether the existing Studio automation can do them, and whether a failed comment or pin should fail the publish or only warn.
- Never double-comment: the existing upload state file (`STATE_PUBLISHED`) is the guard, same as for publish.
