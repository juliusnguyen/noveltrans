# Feature: disable / enable a multi-row selection from the right-click menu

## Request (original)

> support disable by multi-select (in right click). plan and then do the implement

## Context

Feature 098 (CHAPTER-DISABLE) added a per-chapter enabled flag, toggled one row at a time
through a checkbox column in the chapter lists of `Tải truyện`, `Dịch` and `Nghe audio`
(`widgets.py` model → `enabled_toggled(int, bool)` → each tab's `_on_enabled_toggled`).
Disabling a long run of chapters means clicking every checkbox.

## Goal

Select several rows (Shift/Ctrl/⌘-click — the tables already use `ExtendedSelection`),
right-click, and disable — or re-enable — all of them in one action, in every chapter list
that has the checkbox. Same flag, same persistence and downstream effects as the checkbox.
