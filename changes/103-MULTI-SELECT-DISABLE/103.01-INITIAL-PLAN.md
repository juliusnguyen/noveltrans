## Verified facts this plan rests on

| Claim | Evidence |
|---|---|

## Design

- **D1. Batch path, not N × checkbox.** `NovelProject.set_enabled_many(indices, enabled)` — one
  transaction (`executemany`). Model `set_rows_enabled(rows, enabled)` mutates in place, emits
  one `dataChanged` over the affected span and one new `enabled_batch_toggled(list, bool)`
  (chapter indices). The tab handler writes once and does not re-read chapters.
  `enabled_toggled(int, bool)` and the checkbox path stay unchanged.
- **D2. One shared menu helper** `add_enable_actions(menu, table, model, index)` in `widgets.py`:
  rows = selection if the click is inside it, else the clicked row (lifted from
  `TranslateTab._menu_rows` as `menu_source_rows`). "Bỏ qua chương này" / "Bỏ qua N chương"
  when any selected chapter is enabled; "Bật lại chương này" / "Bật lại N chương" when any is
  disabled; both when mixed. Never greyed out (matches the checkbox). Returns early when the
  clicked index is not from `model` (audio's source view).
- **D3. Fill the 098 gap in Nghe audio:** `AudioChapterTableModel` gains the `"Bật"` column
  (index 8), checkbox, tooltip, dimmed row, `enabled_toggled` + batch signal; `tab_audio.py`
  gains `_on_enabled_toggled`. Side effect: the saved "chapters.audio" sort resets once
  (column count changed) — acceptable.

## Steps

1. `storage/project.py`: `set_enabled_many`.
2. `widgets.py`: `_apply_rows_enabled` helper; `ChapterTableModel.enabled_batch_toggled` +
   `set_rows_enabled`; audio model checkbox column; `menu_source_rows`; `add_enable_actions`.
3. `tab_scrape.py`: `_table_context_actions` wrapper (download actions, then enable actions);
   batch handler.
4. `tab_translate.py`: enable actions at the end of `_table_context_actions`; batch handler;
   `_menu_rows` → `menu_source_rows`.
5. `tab_audio.py`: checkbox + batch handlers, enable actions in `_table_context_actions`,
   column width.
6. Tests: project bulk setter; model batch (gapped indices, no-op emits nothing); audio
   checkbox; helper labels / mixed / proxy-sorted mapping / foreign model; per-tab menu
   wiring incl. local novel (scrape) and source view (audio).

## Out of scope

- A "job running" tooltip on the new items.
