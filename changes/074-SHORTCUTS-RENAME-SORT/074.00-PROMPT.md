# 074 — Shortcuts, Novel Rename, Sortable Lists

## Request

1. **Keyboard shortcuts** — allow standard shortcut keys throughout the app
   (e.g. `Cmd+C` to copy, `Cmd+V` to paste, `Cmd+X`, `Cmd+A`, `Cmd+Z`, etc.),
   so text fields and lists behave like a normal macOS/Windows app.

2. **Rename a novel** — allow editing the name of a novel. Adjusting the name
   must propagate to every function of the novel (folders/paths, database
   records, generated files, exports, uploads — everywhere the novel name is
   used), so nothing breaks after a rename.

3. **Sortable lists** — allow sorting in every list in the app.
