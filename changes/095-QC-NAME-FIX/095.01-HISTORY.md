# 095-QC-NAME-FIX — History

## [FEAT] Fix a name slip in place, pair by pair, after review — 2026-09-14

The follow-up offered after 094: a chapter flagged for a character name spelt differently
from the rest of the novel was re-translated in full to change one word.

### Why it is reviewed, not automatic

The first version applied every fix the consistency check could name. A read-only run over
the library before shipping showed that is unsafe: 116 flagged chapters across 7 novels,
and many of the rewrites would have written the check's own false positives into the text —
`Nhưng Sơn Hải → Đoạn Sơn Hải` (a place), `Chân Trúc Cơ → Ngã Trúc Cơ` (a cultivation
stage), `Tân Tông Chủ → Niếp Tông Chủ` ("the new sect leader"), `Tề Quốc Công → Tô Quốc
Công` (a different duke). A glossary name whose tail is an ordinary word or a title makes
any capitalised word before it look like a misspelt surname. Real slips were there too
(`Doan Chí Bình → Doãn Chí Bình`, `Châu Bá Thông → Chu Bá Thông`). So: propose, review,
apply only what was approved.

### Changes

- `translators/qc.py`
  - New code `QC_NAME_VARIANT` ("Tên riêng viết khác cả truyện") for the consistency check,
    split from `QC_NAME_DRIFT`, which stays for the glossary check. Only the first is
    fixable: the glossary check knows a name is missing, never what replaced it.
  - `NameProfile.surface` — the canonical first syllable as the novel writes it. Names are
    compared i/y-folded, but "Lí" must never be written where the novel says "Lý".
  - `propose_name_fixes()` groups every odd spelling across the chosen chapters into a
    `NameFixProposal` (wrong, right, occurrences, chapters, a short example).
  - `fix_name_variants(text, profile, *, approved)` rewrites only approved keys. `approved`
    is required, never defaulted to "all".
  - A sentence-initial slip is fixed only when the same chapter also uses that spelling
    mid-sentence, so "Còn Chí Bình thì sao?" is never touched.
  - `_prefix_matches` rewritten from a regex tried at every character into `str.find` plus
    a backward walk: 126 s → 2.3 s to profile the 1793-chapter novel. The QC scan paid the
    old cost before checking its first chapter. A test compares it with the regex on edge
    cases (tabs, double spaces, digits, overlapping and glued stems); a run over the whole
    library found identical profiles and identical verdicts on every chapter.
- `storage/project.py`: `save_name_fix()` writes title and body, lifts the QC mark, and
  leaves `translator`/`target_lang` alone — no engine produced the edit.
- `gui/workers.py`: `split_retranslation` returns a `RetranslationPlan` (title-only,
  name-fix, full). `TranslateWorker(name_fix=, approved_names=, name_profile=)` routes
  approved chapters to `_fix_names`, which never calls an engine, then re-judges the
  chapter (the judge had not read a name-flagged body). It uses the profile the proposals
  were computed from, so what is applied is exactly what was reviewed.
- `gui/qc_dialog.py`: `NameFixReviewDialog` — one row per pair with count, chapters and an
  example; **nothing ticked by default**; the intro names the false-positive pattern.
  Continue with none ticked leaves the name chapters as they are; "Huỷ dịch lại" cancels
  the whole re-translation. The result view's live line counts "chỉ sửa tên riêng".
- `gui/tab_translate.py`: `_retranslate_qc_failures` asks for review BEFORE clearing any
  chapter, drops unapproved name chapters from the run, and passes the approved keys and
  profile to the worker. With nothing left to propose (novel changed since the scan) the
  chapters are just re-checked.

### Known limits

- Building the proposals runs on the GUI thread with a wait cursor: ~2.5 s on the largest
  novel.
- Existing `name_drift` verdicts written by the consistency check before this change still
  go to full re-translation until the chapter is scanned again.
- A refused pair is not remembered; the next scan flags it again.

### Verification

New tests: fixer and proposals (approval required, nothing unapproved written, grouping
and example, "Lý" surface, sentence-start rule, honorifics, established alternatives),
matcher equivalence with the regex, storage write, worker (approved pair fixed with no
engine call, unapproved left and still marked, judge re-reads the body, reviewed profile
used), review dialog (starts unticked), tab flow (approved reach worker, unticked left out,
cancel clears nothing). Full suite 3784 passed; ruff clean.
