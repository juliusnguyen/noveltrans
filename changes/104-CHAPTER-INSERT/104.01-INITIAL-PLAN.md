# Plan: insert a chapter above / below from the right-click menu (feature 104)

Scope (user): local **and** scraped novels.

## Verified facts this plan rests on

| Claim | Evidence |
|---|---|
| `idx` is the chapter's identity and its number (`idx + 1`) | `chapters.idx INTEGER PRIMARY KEY` (`project.py:57`); number column `widgets.py:534/858`, exporter prefix `exporters/base.py:70`, QC / find-replace labels |
| Delete leaves a hole; append never fills one | `delete_chapter` (`project.py:413`), `add_chapters` (`:380`) — both to avoid invalidating number-keyed files |
| Row data moves with the row | audio path/voice/fingerprint, translation, QC, `enabled`, `title_custom` are columns |
| Number-keyed artifacts on disk do NOT move | per-chapter audio `{n:04d}-…` (`workers.py:1818`, read back by `cleanup.chapter_index`); merged audio `{slug}-{a:04d}-{b:04d}` (`workers.py:2347`); video part folders by span (`tts/video.py:631`) incl. `.upload.json`; `video_manual_windows.json`; `video_part_offsets.json` |
| Rescan writes `ref.index → idx` | `replace_toc` (`project.py:353`), `ON CONFLICT(idx)` — would clobber shifted rows |
| A manual row in a scraped novel would be queued for download and fail | `pending_download` (`:481`), `DownloadWorker._select_chapters` (`workers.py:3159`), `ScrapeTab._selected_pending` (`tab_scrape.py:583`) |
| Content can be pasted for any chapter | translate tab "Bản gốc" pane is editable (`tab_translate.py:405/438`) |

## Design

- **D1. Shift `idx`, but only up to the first hole.** `insert_chapter(at)` shifts `[at, q)` by +1
  where `q` is the first unused idx ≥ at. A hole from a delete absorbs the insert. Rejected
  alternative: a separate `position` column — ~20 places derive the number from idx and all
  on-disk names are keyed by it.
- **D2. Refuse when the shift would desync files.** `insert_blockers(project, at)` lists
  reasons (Vietnamese) when any renumbered chapter has audio, or any video part folder /
  merged audio / manual window / part-offset anchor overlaps the renumbered range.
- **D3. Rescan survival via `toc_index`.** New column = the site's TOC position, −1 for a
  hand-made chapter. Migration back-fills `toc_index = idx` for scraped novels (true until
  now). `replace_toc` matches by `toc_index`, never touches manual rows, and places new refs
  after their predecessor (identical numbering when there are no manual rows).
- **D4. Download skips rows without a URL** (`pending_download`, worker, tab selection).
- **D5. UI only in Tải truyện**, disabled while any job runs in the workspace. Manual rows
  can be deleted on scraped novels too (a rescan can't bring them back).

## Steps

1. `models.Chapter`: `toc_index: int = -1`, `is_manual`.
2. `storage/project.py`: schema + migration + row mapping; `replace_toc` by `toc_index`;
   `pending_download` url filter; `insertion_span`; `insert_chapter`.
3. `chapter_insert.py`: `insert_blockers`.
4. `tab_scrape.py`: "Thêm chương phía trên / phía dưới", `_insert_chapter`, delete for manual
   rows, `workspace_busy` hook (set in `workspace.py`), url filter in `_selected_pending`;
   `workers.py` url filter.
5. Tests: storage (shift, hole, migration, rescan survival incl. new refs / custom title /
   retitle, pending_download), blockers, tab wiring.

## Known limits

- Number text inside titles ("第12章", "Chương 3: …") is not rewritten.
- Another workspace with the same novel open isn't covered by the busy hook (same as today).
