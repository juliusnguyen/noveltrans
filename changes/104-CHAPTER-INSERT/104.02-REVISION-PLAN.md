## Mapping (insert at idx `at`, new number N = at+1, `(at, q) = insertion_span(at)`)

- `f(x) = x+1 if N <= x <= q else x` — old numbers N..q shift.
- `f_first(x) = x+1 if N <= x <= q+1 else x` — q+1 is always an empty slot; a span starting
  there must not overlap its neighbour.
- `owner` = old number of the right-clicked chapter; in the hole-fill case (q == at) N if some
  span already covers N. **Append below the novel's last chapter → owner None** (starts the
  next part rather than growing a possibly published last part).
- Containing span (a <= owner <= b): `(min(a, N), max(f(b), N))`; any other: `(f_first(a), f(b))`.

## Artifacts

| Artifact | Handling |
|---|---|
| Per-chapter audio `NNNN-…` (+ `.cues.json`, orphans) in N..q | rename to n+1; row `audio_path` relinked in the insert's own transaction (`cleanup.chapter_index` reads the number from the name) |

| OneDrive manifest, `.upload.json` `subtitle_file`, `.title.txt` | untouched (renamed files re-upload; part numbers don't move) |

`insert_chapter(..., audio_relinks=…)`; any failure rolls back moves + JSON and re-raises;
merged-audio deletes after commit (warnings only). Collisions refuse the whole plan.

## Reading the marked part

- `tts/video.resolve_part_video` — per-folder > legacy flat > marked folder covering the window
  (the planner trims a window to voiced chapters, so an edge insert without audio would
  otherwise miss its folder) > default. Used by `tab_video._part_output_path`, `VideoWorker`,
  `SubtitleWorker`.
- `VideoWorker` clears rendered numbers from the marker after a successful render.
- `cleanup.covered_chapters` / `_parts_with_subtitles` skip marked folders.
- `tab_video._resync_description_sidecars` skips marked folders; uploads skip unpublished
  marked parts.
