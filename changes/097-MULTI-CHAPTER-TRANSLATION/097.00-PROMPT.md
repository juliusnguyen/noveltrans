# Feature: Multi-Chapter Concurrent Translation

## Request (original, Vietnamese)

Trong `Dịch`, cho phép dịch cùng lúc từ 2 chương trở lên, có thể chỉnh trong setting. Trạng thái của từng chương sẽ được cập nhật là `Đang dịch` khi trong quá trình dịch.

## Translation / summary

In the `Dịch` (Translate) feature, allow translating 2 or more chapters concurrently, with the concurrency limit configurable in settings. Each chapter's status should update to `Đang dịch` ("Translating") while it is being translated.

## Requirements

- Add a setting to control how many chapters can be translated in parallel (minimum 2, configurable by the user).
- The translation pipeline must process multiple chapters concurrently up to that configured limit, instead of strictly one at a time.
- Each chapter's status must be updated to `Đang dịch` when its translation starts, and reflect completion/failure states as it does today, but now correctly per-chapter while others are also in flight.
- No regression to existing single-chapter translation behavior when concurrency is set to 1 (or as a lower bound, if that's still allowed).
