# 050 — Hide the Dock icon while running in the menu bar

> when the app run the job, and when I close it to made the app appear in the bar, I want
> it also disappear in the dock

Follows 049. Closing the window already hides the app to the macOS menu bar with the job
still running — but the Dock icon stays. It should go away too, and come back when the
window is reopened.

## Approach

macOS `NSApplication.setActivationPolicy:` switched at runtime:

* `Regular` (0) — Dock icon + application menu bar (window visible)
* `Accessory` (1) — no Dock icon, menu-bar item only (hidden to the menu bar)

pyobjc is not a dependency; `libobjc` is reachable through `ctypes`, and switching both
ways was verified against a live `QApplication` before writing any of this.

## Known consequences (from 049's design)

These are real losses, accepted as the cost of what was asked for:

* **The Dock badge stops working while hidden.** 049 badges the Dock when a job finishes
  with the window hidden, and called that the *reliable* half of the signal (a tray
  `showMessage` can be silently dropped for an unsigned bundle). No Dock tile → no badge.
* **Dock-click re-show stops working while hidden.** No icon to click; the menu-bar icon
  becomes the only way back.
* **⌘Q stops working while hidden.** In Accessory mode the app does not own the menu bar,
  so the shortcut is not delivered. `Thoát` in the popup remains.

`LSUIElement` in Info.plist is still NOT set — that would remove the Dock icon
permanently, including while the window is open. This is the runtime, reversible version.
