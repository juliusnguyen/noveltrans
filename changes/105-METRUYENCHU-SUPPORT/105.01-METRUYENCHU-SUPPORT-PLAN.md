# 105 METRUYENCHU-SUPPORT: Implementation Plan

Target: https://metruyenchu.com.vn/ca-trieu-van-vo-deu-nghe-ta-tieng-long
Novel: "Cả Triều Văn Võ Đều Nghe Ta Tiếng Lòng" (author Ẩm Tửu Thính Vũ), status "Đang cập nhật" (still updating), about 342 chapters at the time of investigation.

## 0. Summary

- **Plain `HttpClient` is enough.** Book page, chapter-list AJAX endpoint (JSON) and normal chapter bodies all return HTTP 200 to plain GET. No browser path for v1.
- **Metadata** from static HTML: `h1[itemprop=name]`, `a[itemprop=author]`, `meta[name=description]`.
- **Chapter list:** page 1 is static (100 chapters inside `#chapter-list`). Pages 2+ come from `GET /get/listchap/<rid>?page=N` (JSON `{"data": "<li>...</li>"}`), where `rid` is `var rid = '83685';` in the inline script. Full TOC is 1 to 342 with no gaps (page 4 has one duplicate).
- **Chapter bodies:** static `<p>` elements inside `div.truyen`.
- **Blocker:** the final chapter (342) serves a verification gate (`#formcode`, `#form-code`, `control-last`) that asks a human to search a keyword on Google and paste a code via a third-party service (`tf3t.net`). The adapter must **detect and report** this, not automate or bypass it.
- **Slugs are unreliable** (`chuong-chuong-301-...`, `chuong-chuong--<hash>` with no number, `chuong-tiep-<hash>`). Chapter numbers come from the link text (`Chương NNN:`), not the URL.

## 1. Evidence

| Item | Finding |
|---|---|
| Title | `h1[itemprop=name]`. Avoid `og:title` (has suffix " - Đọc Truyện Chữ Convert"). Entities like `&#245;` must be decoded. |
| Author | `a[itemprop=author]` (link `/tac-gia/am-tuu-thinh-vu`). |
| Description | `meta[name=description]`; starts with "Truyện ... của tác giả: ...". |
| Genres | `li.li--genres a` (not stored; `NovelMeta` has no genre field). |
| Chapter list page 1 | Anchors inside `#chapter-list` use single-quoted hrefs. Sidebar/"next" anchors also match `/chuong-`, so selector must be scoped to `#chapter-list a`. |
| Paging | `div.paging` with `onclick='page(83685,N)'`. Max N hint is 4. Page 4's own paging wraps back to page 1, so "next link" is not a stop condition: stop at first page with zero numbered links. |
| AJAX | `/get/listchap/83685?page=2` → 100 chapters (101–200); `page=3` → 100 (201–300); `page=4` → 43 anchors / 42 unique (301–342). |
| Chapter body | Chapter 1, 2, 150 return full bodies in `div.truyen`. Chapter 2 has a `Tải Ebook` button whose text would leak through a naive `<p>` regex. |
| Chapter 342 | 19 KB stub: no `.truyen` body; `#formcode` loading gif filled by `/theme/js/_code.js` from `tf3t.net`. Sets `_g_83685` cookie for 24h after human verification. |
| Title tag | Chapter 342 title pattern differs (`... - Chương 342: Toàn Văn Hoàn`). Use the TOC title for `ChapterRef.title`. |
| Encoding | `text/html; charset=utf-8`. |
| Anti-bot | `server: cloudflare`, challenge beacon present but all checked requests returned 200. `cf_browser.looks_like_challenge` can be reused for detection. |
| Latency | ~0.5 s chapter pages, ~2–4 s AJAX. Full run ~347 requests, roughly 15–25 min at `delay_seconds=1.5`. |

Not verified: whether `X-Requested-With`/Referer headers are required by the AJAX endpoint (test without them in step 2); og:image cover; whether `metruyenchuvn.com` (in JSON-LD) redirects here; whether the gate applies to chapters beyond 342.

## 2. Approach

Use a **plain `HttpClient` `SiteAdapter`** (not browser-based). Browser adapters add Chromium dependency and windows, and nothing here needs JS. The gate cannot be solved legitimately by a browser either, so a browser would only automate past a human step. Keep `cf_browser` as a later fallback if Cloudflare starts serving challenges.

## 4. Adapter design

### Constants
- `_ORIGIN = "https://metruyenchu.com.vn"`
- `_SLUG_RE = re.compile(r"metruyenchu\.com\.vn/([a-z0-9-]+)")` (landing-page normalization)
- `_RID_RE = re.compile(r"var\s+rid\s*=\s*'(\d+)'")`, fallback `/get/listchap/(\d+)` or `page\((\d+),`
- `_CH_NUM_RE = re.compile(r"^\s*Chương\s+(\d+)\s*:?")` applied to unescaped link text
- `_GATE_MARKERS = ('id="formcode"', 'id="form-code"', "control-last")`, combined with "no `div.truyen` paragraphs" to decide a gate
- `_MAX_TOC_PAGES = 500`
- `content_is_translated = False`, `source_lang = "vi"`

### Methods
- **`fetch_metadata(url)`**: GET landing page (normalize URL via `_SLUG_RE`). Title from `h1[itemprop=name]`, fallback `og:title` split on " - Đọc Truyện". Author from `a[itemprop=author]`. Description from `meta[name=description]`. Cover from `og:image` if present. Raise `ScrapeError` on empty title.
- **`fetch_chapter_list(url)`**:
  1. GET landing page once; read `rid`; parse `#chapter-list a` as page 1.
  2. For `n = 2, 3, ...` GET `f"{_ORIGIN}/get/listchap/{rid}?page={n}"` with `client.get`, parse `.json()["data"]`. Wrap `ValueError`/`KeyError` in `ScrapeError`.
  3. From each fragment select `a[href*="/chuong-"]`, keep those whose text matches `_CH_NUM_RE`, dedupe by number (first wins).
  4. Stop at first page with zero numbered links, or at `_MAX_TOC_PAGES`.
  5. Sort by number; `ChapterRef(index=i, title=normalized, url=urljoin(_ORIGIN, href))`; normalize whitespace and NFC.
  6. Raise `ScrapeError` if empty. If numbering has gaps, raise a clear error rather than silently returning a partial list.
- **`fetch_chapter(ref)`**:
  1. `html = client.get_html(ref.url)`.
  2. If `looks_like_challenge(html)`: raise a clear Cloudflare `ScrapeError`.
  3. If gate markers present and no body paragraphs: raise `ScrapeError` with a Vietnamese message: the chapter requires a manual verification step on the site; open it in a browser, complete the step, then retry. **Never request `tf3t.net` and never set `_g_<rid>`.**
  4. Else paragraphs from `div.truyen p`, `get_text(" ", strip=True)`, drop empties, drop footer disclaimers ("MeTruyenChu – ...", "Truyện được sưu tầm ..."), drop a leading line equal to `ref.title`, NFC, replace `\xa0`.
  5. No paragraphs and no gate: raise `ScrapeError("Chapter content is empty")`, or "not found" if the container is missing.
  6. Return `"\n\n".join(lines)`.

## 6. Test plan

Classes: `TestRegistry`, `TestMetadata`, `TestChapterList`, `TestChapter`.

- **Registry:** `matches` true for landing and chapter URLs, false for other hosts; `adapter_for_url` returns the adapter.
- **Metadata:** title, author, description; entities decode (`Võ`, `Lòng`); `source_lang == "vi"`; chapter URL normalizes to landing URL.
- **Chapter list:** page 1 counts only `#chapter-list` (sidebar anchor excluded); mocked pages 2–3; page 4 duplicate deduped; page 5 empty stops the loop; sorted, 0-based contiguous `index`; titles start with `Chương`, whitespace normalized, URLs absolute; slug oddities (`chuong-chuong-301-...`, `chuong-chuong--<hash>` → number from title, `chuong-tiep-...` excluded if unnumbered); missing `#chapter-list` → `ScrapeError`; numbering gap → error.
- **Chapter body:** normal chapter → paragraphs joined by `\n\n`; `Tải Ebook` excluded; footer disclaimer removed; NFC normalization (one decomposed string); gated fixture → `ScrapeError` with the verification message and **no request to `tf3t.net`** (`responses` fails on unmatched URLs, which enforces this); challenge markup → clear error; empty `div.truyen` → `ScrapeError`.
- Before committing, grep fixtures to confirm no real novel body phrases.

## 8. Risks

1. **Rate limiting / slow AJAX:** keep default delay and retry/backoff; no parallel fetching.
2. **Cloudflare escalation:** `looks_like_challenge` detects it; browser fallback can be added later.
3. **Verification gate on chapter 342:** adapter reports it; batch shows one failed chapter. Bypass is out of scope.
4. **Numbering:** derive from titles, scope selectors, dedupe, check contiguity.
5. **Growing list:** status "Đang cập nhật"; never hardcode 342.
6. **Encoding:** BeautifulSoup + `html.unescape`, NFC, replace `\xa0`.
7. **Stray text:** scope to `div.truyen`, filter known strings.
8. **Second domain** `metruyenchuvn.com`: do not add to `url_patterns` until verified.
9. **Misreading a genuinely empty chapter as gated:** gate markers are the evidence; verify on a second non-final chapter.
10. **Fixture drift:** keep fixtures small; document structure assumptions at the top of the module.

## 9. Open questions

1. **Gate policy in batch downloads:** mark that chapter failed and continue (recommended), or stop the batch (needs worker change)?
2. **Cookie paste support** (like medoctruyen's `_g_<rid>`): this automates the outcome of a human verification step, so it is a policy call. Not included in this plan.
3. **Domains:** only `metruyenchu.com.vn`, or also `metruyenchuvn.com`?
4. **Language flag:** confirm `source_lang="vi"`, `content_is_translated=False`, as with medoctruyen.
5. **Description:** strip the "Truyện ... của tác giả: ..." prefix?
