# 110 PUBLISH-CONTENT-CHECK-POPUP

## Problem

When uploading with the **Publish** option, the upload fails and a pop-up appears:

> **We're still checking your content**
> - This usually takes a few minutes
> - We recommend keeping your content private until checks complete
> - If you publish now, it may be limited or removed
>
> [Publish anyway] [Got it]

Screenshot: `/Users/juliusnguyen/Desktop/Screenshot 2026-11-26 at 23.11.42.png`

The pop-up appears to come from the upload/publish flow of the target platform (it looks like YouTube Studio's pre-publish content check). The app treats it as a failure instead of handling it.

## Goal

Make the publish flow handle the "still checking your content" state correctly. To be confirmed during planning:

- Find the code path that performs the publish step and where the failure is detected.
- Decide the expected behaviour: wait/poll until checks complete, publish as private and retry later, or surface a clear message to the user.
- Make sure a publish that hits this state does not silently fail.
