# 094-QC-CHINESE-TITLE — History

## [FIX] QC passed a chapter whose title was still in Chinese — 2026-09-14

Reported on twkan.com/book/3554, chapter 1767: a good Vietnamese body under the heading
`第1756章 星降噬凡軀`, marked "Đạt" by Kiểm tra chất lượng.

### Cause

`check_translation` took a `title` argument and never read it — every check ran on the body.
The title itself comes from `Translator._safe_title`, which falls back to the SOURCE title
when the engine errors or returns something implausible, and `_translate_with_retry` keeps
its least-bad attempt even when it still has CJK. Either path saves a Chinese heading with
no error, and QC had nothing that looked.

### Measured

Across the library, 14 of 4607 translated titles carry CJK, all from `CLI (agy)`, all QC
"ok": 13 are the source title saved back unchanged, one is half translated
(`第1382章 曾Lý Phàm之死`). The other 4593 carry zero CJK — nothing in the 1–4 range — so
the threshold is a single glyph. Re-run against the library after the change: exactly those
14 flagged, 5143 pass.

### Changes

- `translators/qc.py`: new code `QC_TITLE_UNTRANSLATED` ("Tiêu đề còn chữ Hán") and
  `check_title`. `check_translation` now runs the body checks (moved unchanged into
  `_check_body`) and checks the title only once the body passed, so a body in the wrong
  language is still what gets reported.
- Ranked mildest in `QC_SEVERITY`, below Hán-Việt: `KEEP_BEST` must never trade a good
  body for a clean heading.
- No retry hint (`NO_HINT_CODES`): the hint reaches the body prompt only, where "translate
  the title" would invite a heading into the body. The retry still helps — the failure is
  non-deterministic and the next attempt asks for the title again.
- The hint/label guard test now exempts `NO_HINT_CODES` explicitly.

### Existing verdicts

Chapters already judged "ok" are skipped by a normal scan (their fingerprint has not
changed). Re-scan with "Tất cả chương đã dịch trong khoảng (kiểm tra lại từ đầu)" to flag the 14 existing chapters.

### Verification

7 new tests in `TestTitleCheck` plus a severity test; full suite 3742 passed.

## [FEAT] Re-translate only the title when the title is the only failure — 2026-09-14

Asked straight after the fix above: "↻ Dịch lại chương đã chọn" cleared the chapter and
translated title AND body again — ~17 000 characters of a body that had passed, to fix an
11-character heading, with the risk of the new body coming back worse.

### Changes

- `translators/base.py`: public `translate_title()` — the title half of `translate_chapter`
  (same `_safe_title` guard, same watermark filter). `translate_chapter` now calls it, so
  the two cannot drift apart.
- `translators/qc.py`: `QcAttemptPlan.translate_title` (optional) and
  `retranslate_title_with_qc()` — walks the same engine chain with the same per-engine
  attempts, checks each reply with `check_title`, and is strict: it returns a title only on
  a pass, never a Chinese one, and never raises (an engine error moves to the next plan).
- `storage/project.py`: `save_title_translation()` writes `translated_title` only, lifts the
  QC error mark; body and `translator` untouched.
- `gui/workers.py`: `split_retranslation()` decides title-only vs full — title-only needs
  code `title_untranslated` AND a translated body. `TranslateWorker(title_only=…)` routes
  those chapters to `_retranslate_title`, which never sends the body. With QC off, the tab's
  own engine is used once. After the title is saved the whole chapter is re-judged, LLM
  judge included: the title failure had stopped the scan before the judge ever read the
  body, so this is the body's first full verdict. On failure the old title stays and the
  row stays red.
- `gui/tab_translate.py`: the QC result view now connects to `_retranslate_qc_failures`,
  which clears only the full-retranslation chapters. `_retranslate_indices` (the Name
  Glossary dialog's path) is unchanged.
- `gui/qc_dialog.py`: a live line under the table — "Sẽ dịch lại: N chương chỉ dịch lại tiêu
  đề — giữ nguyên nội dung; M chương dịch lại toàn bộ — xoá bản dịch hiện tại." — counted
  by `split_retranslation`, the same function the worker is handed. It replaces the fixed
  "Dịch lại sẽ xoá bản dịch hiện tại" sentence, which is no longer true for every chapter.

### Cost

One title attempt is one short `translate()` call; `_translate_with_retry` may repeat it up
to 3 times while the reply still has CJK. With the default 2 attempts per engine that is at
most 6 heading-sized calls per engine — against one full chapter per attempt before.

### Verification

19 new tests: the pure loop (pass, retry + fallback, exhaustion returns no title, engine
error, empty reply, plan without a title callable, stop), `translate_title`, the storage
write, the worker (no body call, body byte-for-byte, failure keeps old title and mark, the
judge re-reads the body, QC-off path, bodyless chapter goes full), `split_retranslation`,
the dialog's live line and the tab's selective clear. Full suite 3761 passed; ruff clean.
