# Plan: 108 — character-count columns on the Translate tab

## Decisions
- **Append, don't insert.** New columns are indices 9 (original chars) and 10 (translation chars), after ENABLED_COLUMN = 8. No existing index moves, so the retranslate/enabled delegates, widths, and the column-guard tests stay valid.
- **Translate-only subclass.** `TranslateChapterTableModel(ChapterTableModel)` is used only by tab_translate. The scrape tab, which shares the base model, keeps 9 columns.
- **Same counting rule as the audio tab:** `len(text)` on the raw string (whitespace included). Blank, not 0, when the text is empty. Original = `chapter.content`, translation = `chapter.translated` (not `translated_raw`, which is the undo copy).

## Steps
1. `gui/widgets.py`: add pure helpers `format_char_count(text) -> str` (blank for empty/None, else `f"{n:,}"`) and `char_count(text) -> int`, next to `format_duration`.
2. `gui/widgets.py`: add `TranslateChapterTableModel(ChapterTableModel)` with `COLUMNS` extended by two headers, `ORIG_CHARS_COLUMN = 9`, `TRANS_CHARS_COLUMN = 10`; `data()` handles DisplayRole, TextAlignment (right), and SORT_ROLE (int) for the new columns and delegates everything else to super.
3. `gui/tab_translate.py`: construct `TranslateChapterTableModel(self)` instead of `ChapterTableModel(self)`; set fixed widths for columns 9 and 10.
4. Verify every write path to `content`/`translated` in tab_translate is followed by `update_chapter` or `set_chapters` (grep the callers of save_content / save_translation / restore_translation).
5. Tests: pure helpers; model data (text, blank, right alignment, numeric sort, disabled-row foreground, raw copy ignored); dataChanged spans the new columns; scrape model still has 9 columns; existing guard tests still green.
6. Full test suite.

## Risks
- The Translate tab's saved sort resets once (column count changes).
- Cross-tab staleness: a download in the scrape tab does not refresh the translate table until a reload. Pre-existing for all columns.
- Stored text may include the title line; counts follow the same convention as the audio tab.
