# 066 — Source-audio video fails in batch mode

## Report (user)

> Got this error when generating the video from audio downloaded via `Audio từ nguồn`
> and using `Tạo video`. `Tạo` (single video, per-row) is OK.

Error dialog:

> **Chưa tải mục audio nào từ trang nguồn trong phạm vi đã chọn.**

## Expected

With the voice selector set to `Audio từ nguồn` (`SOURCE_AUDIO_KEY`), the main
**Tạo video** button should render the site's audio edition — the same parts the
table already previews — instead of failing with "chưa tải mục audio nào".

## Findings (root cause)

Two places plan over *chapter* audio while ignoring the source-audio edition:

1. `src/noveltrans/gui/workers.py` — `VideoWorker.run()` planning chain tests
   `self.mode == "batch"` **before** `self.source_audio`:

   ```
   if self.explicit_windows is not None: ...
   elif self.mode == "batch":            # ← wins for a source-audio batch run
       ... plan_locked_video_windows(project.chapters(), self.voice, ...)
   elif self.source_audio:
       ... plan_source_windows(project.source_audio(), ...)
   ```

   In batch mode with `source_audio=True` it plans over `project.chapters()` with
   `voice="__source_audio__"`, which matches nothing → empty windows →
   `_nothing_message()` → the dialog above.

   Why the working paths work:
   - per-row **Tạo / Tạo lại** → `_render_one` → `mode="range"` → falls through to
     the `source_audio` branch.
   - right-click multi-select **Tạo video** → `explicit_windows` → planning skipped.

2. `src/noveltrans/gui/tab_video.py` — `_redo_all_videos` ("Tạo lại tất cả video")
   calls `plan_merge_windows(self.project.chapters(), voice, ...)` directly rather
   than going through `_windows_for_current_selection()`, which *does* branch on
   `SOURCE_AUDIO_KEY`. So redo-all is broken for source audio too (it stops at its
   own "Chưa có audio" dialog).

Note `MergeWorker.run()` already tests `source_audio` first and is correct — the
same fix shape should apply to `VideoWorker`.

## Scope

- Make `VideoWorker` honor `source_audio` regardless of `mode` (source audio has no
  batch grid / manual-split / committed-window locking — those are chapter concepts).
- Make `_redo_all_videos` reuse `_windows_for_current_selection()` so it agrees with
  the table and with `_start_video`.
- Regression tests for both.
