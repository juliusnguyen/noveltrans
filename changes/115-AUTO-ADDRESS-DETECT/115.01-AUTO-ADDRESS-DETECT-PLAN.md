# 115.01 AUTO-ADDRESS-DETECT-PLAN

Follow-up to `113-PRONOUN-CONSISTENCY`.

## Problem

Feature 113 required opening `🗣 Xưng hô` manually and clicking `🔎 Dò từ bản dịch` before or after translating. When translating a novel chapter by chapter without opening the dialog first, `address.json` remained empty and later chapters did not benefit from an auto-populated address table. Additionally, `AddressScanWorker` defaulted to scanning existing translations instead of letting users scan directly from the original source text when translations already exist.

## Design

1. **Per-chapter extraction from source (`translators/address.py`):**
   - Extend `build_extract_prompt(..., source_lang="zh")` so source-based prompts handle both Chinese (`tiếng Trung`) and non-Chinese source texts (`bản gốc`), asking the model to analyze relationship semantics (age, hierarchy, closeness, tone) and propose Vietnamese `xưng | gọi` terms.
   - Add `should_extract_chapter(text, known_names, existing)` so extraction only runs when a chapter introduces at least one known character (`names.json`) who has **no row anywhere yet** (neither `speaker` nor `listener`) in `existing` — or when `names.json` is empty and the chapter has dialogue. Chapters with only already-covered characters or pure scenery are skipped at zero extra LLM cost.
   - Add `extract_chapter_address(...)` to run `dialogue_excerpt` → `build_extract_prompt(from_source=True)` → `parse_extract_reply` → `aggregate`, returning only pairs missing from `existing`.

2. **Automatic update during translation (`gui/workers.py`):**
   - Add `auto_address: bool = True` on `TranslateWorker` (wired to `AppConfig.auto_detect_address`, default `True`).
   - Before translating each chapter to Vietnamese (`target_lang == "vi"`) with an engine supporting both `supports_completion` and `supports_context`, `_maybe_auto_detect_address` checks `should_extract_chapter`, extracts missing pairs from the name-substituted source text, merges them into `address.json` via `merge_extracted` under `_address_lock` (thread-safe for parallel workers, never overwriting existing rows), updates `self._address`, and immediately injects the updated rules into the chapter's translation prompt.
   - Extraction errors are non-fatal so chapter translation never fails because of auto-detection.

3. **Config and UI (`config.py`, `gui/tab_translate.py`, `gui/address_table_dialog.py`):**
   - Persist `AppConfig.auto_detect_address` (default `True`).
   - Add two checkboxes in `AddressTableDialog`:
     - `Tự động dò từ bản gốc khi dịch từng chương` (`config.auto_detect_address`).
     - `Dò từ bản gốc (kể cả chương đã dịch)` (`prefer_source` on `AddressScanWorker`).
