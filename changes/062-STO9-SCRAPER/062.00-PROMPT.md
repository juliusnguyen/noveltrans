# 062 — STO9 Scraper

Add scraper support for this site:

https://sto9.com/book/13908/index.html

Follow the existing adapter conventions (see `061-BOOKQQ-SCRAPER` for the most recent example):
- Recognize the site's book/index URLs and chapter URLs.

- Handle encoding, pagination, and any anti-scrape quirks the site has.
